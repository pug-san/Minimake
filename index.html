❓ Help & Instructions
Front Elements
📦 Button
A clickable button. Set the button text and give it a unique name (e.g., "submitBtn"). Use [varName] for variables. Set width/height in pixels to control size, or leave blank to fit the text. Link actions using onClick blocks in the back tab.
📝 Text / Heading
Display text. Pick a tag from the dropdown — <p> for paragraphs, <h1> through <h6> for headings. Use [varName] to insert variables. Style any tag in the CSS tab.
⌨️ Input
A text input field. Set the placeholder text. Use [varName] in the placeholder.
📊 Progress Bar
Shows a progress bar. Set the current value, max value, and width/height in pixels. Use [varName] for dynamic values!
✅ Checkbox
A checkbox with a label. Give it a unique name (e.g., "agreeCheckbox"). Use [varName] in the label. Link actions using onChange blocks in the back tab.
🖼️ Image
Display an image. Double-click the placeholder on the canvas, then click 📁 Choose File to upload an image from your device. Set the width and height in pixels.
Back Elements (Variables & Events)
🔢 Variable
Create a numeric variable. Set a name and value. Reference it in front elements using [varName].
💬 String
Create a text variable. Set a name and text value. Use [varName] to display it.
🖱️ onClick
Link an action to a button. Select the button name from the dropdown and enter the action to perform when clicked.
☑️ onChange
Link an action to a checkbox. Select the checkbox name from the dropdown and enter the action to perform when changed.
🔗 Nesting blocks inside If / Loop
Drag any block onto an if or loop block — the dotted area inside it is a drop zone. Drop between two existing children to insert there: a blue line shows where the new block will land. Drag a child out of the zone to detach it. Tip: drag slowly so you don't accidentally just open the editor.
▶️ When if / loop blocks run
A top-level if is reactive — it runs when the preview loads and after every button click or checkbox change, so it automatically responds to variable updates. Example: if (hp < 1) hp = 10 will reset hp every time something pushes it below 1. Top-level loop blocks run once on load (avoiding surprise side effects). Want a loop to repeat? Put it inside an onClick handler.
👁️ Live Preview
Open the preview and leave it open — it auto-refreshes as you edit elements, blocks, and code.
CSS Tab
🎨 Adding style rules
Click any target in the sidebar (body, p, h1–h6, button, input) to add a rule for that selector. Each rule has font-size, color, font-family, font-weight, and text-align. Leave any field blank (or pick "(inherit)") to skip that property — only filled-in values are applied.
🌈 Setting colors
Use the color picker for a quick swatch, or type a value like #ff6699, red, or rgb(120, 80, 255) in the text field. Click "clear" to remove the color.
🖼️ Page background color
Click + body (page background) in the CSS sidebar and pick a color in the background-color row. The body rule only handles background — for text styling, add a rule for a specific selector like p, h1, etc.
🌄 Background image
In any CSS rule (e.g. + body), click 📁 Choose File in the background-image row to upload an image from your device. It's automatically set to cover + center so it fills the area cleanly.
🅰️ Heading levels h3 / h4 / h5 / h6
All six heading levels are stylable from the CSS tab. Add a rule for each level you use and customize its font-size, weight, etc.
Features
📤 Variable Interpolation
In any front element, use [variableName] to insert values from variables in the back tab. For example, if you have a variable "score" with value "42", use [score] to display it.
🔁 Live variable updates
Variables you create in the Back tab are real JavaScript variables in the preview. So an onClick action like counter++ works, and any element using [counter] will refresh automatically right after the action runs. Use counter = 0 to reset, myText = "hi" for strings, etc.
📐 Drag positions = preview positions
Where you place a block on the Front canvas is exactly where it appears in the preview. The preview is absolutely positioned, so your layout is preserved.
▦ Snap to grid
On by default. Toggle in Settings. When on, dragged elements snap to a 20px grid (visible as faint dots/lines on the canvas) so things line up cleanly.
⬚ Drag to select
Click and drag on empty canvas (or the back-tab background) to draw a selection rectangle. Anything it touches gets selected. Shift+click an element to add/remove it from the selection. Shift+drag on the background adds to the existing selection. Esc clears selection.
📋 Copy / paste / duplicate
Select one or more items, then: Ctrl/⌘+C copy, Ctrl/⌘+X cut, Ctrl/⌘+V paste, Ctrl/⌘+D duplicate, Ctrl/⌘+A select all, Delete/Backspace remove. Pasted items appear with a small offset. For if/loop blocks in the back tab, the entire nested subtree is copied together.
🤝 Group move
When multiple items are selected, dragging any one of them moves the whole group together — useful for repositioning a chunk of UI without re-selecting.
💾 Export & Import
Export your entire project as a .txt file to save it. Import a .txt file to load a saved project. All blocks and their positions will be preserved!
🎨 Themes
Use Dark Mode for a darker interface. Enable Poipole Mode~ for a magical lavender/purple aesthetic that works with both light and dark modes!
