❓ Help & Instructions
Front Elements
📦 Button
A clickable button. You can set the button text and onclick action. Use [varName] to insert variable values.
📝 Text
Display static or dynamic text. Use [varName] to insert variable values from the back tab.
⌨️ Input
A text input field. Set the placeholder text. Use [varName] in the placeholder.
📊 Progress Bar
Shows a progress bar. You can set the current value and max value. Use [varName] for dynamic values!
✅ Checkbox
A checkbox with a label. Use [varName] in the label.
📌 Heading
Heading text (H1, H2, H3). Use [varName] to insert variables.
Back Elements (Variables)
🔢 Variable
Create a numeric variable. Set a name and value. Reference it in front elements using [varName].
💬 String
Create a text variable. Set a name and text value. Use [varName] to display it.
Features
📤 Variable Interpolation
In any front element, use [variableName] to insert values from variables in the back tab. For example, if you have a variable "score" with value "42", use [score] to display it.
💾 Export & Import
Export your entire project as a .txt file to save it. Import a .txt file to load a saved project. All blocks and their positions will be preserved!
🎨 Themes
Use Dark Mode for a darker interface. Enable Poipole Mode~ for a magical lavender/purple aesthetic that works with both light and dark modes!
